How to Use Now Plugin Updater

Overview

Now Plugin Updater is an admin-only tool to discover, select, and install available updates for Store applications on this ServiceNow instance, replacing the per-app flow in the native Application Manager.

Home

Shows the instance release (e.g. Australia · Patch 2), active plugin count, store apps up to date, updates available, and installs in progress.

Wizard — Discover & Select

Lists Store apps with a newer version available (active, visible, previously installed from the Store; excludes static-content, platform-bundled, and UX toolkit components), grouped by product category. Filter and select the apps to update.

Install & Progress

  • Installs run in batches of up to 8 concurrent, triggered with your current admin session (no stored credentials).
  • Progress is polled every 15 seconds from sys_progress_worker.
  • The installed version is verified against the target before marking success.
  • A 400 “Offering plugin id must be specified” error is retried automatically.

Access Control

This page, its data, and the install log are restricted to the admin role.
